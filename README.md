# Wearly

쇼핑몰 상품 URL을 붙여 넣으면 상품 정보를 내 옷장에 추가하고, 내 전신사진에 실제 상품을 입혀 여러 코디를 비교하는 서비스 입니다.

### Live Demo

👉[Wearly 바로 사용해보기](https://wearly-ai-closet.vercel.app/)

## 포함된 기능

- 상품 URL 붙여넣기 및 클립보드 붙여넣기
- 공개 상품 페이지의 Open Graph/JSON-LD 정보 분석
- 상품 페이지의 실제 제품 사진을 옷장 카드에 반영
- 색상·카테고리·계절·스타일 자동 태깅
- 브라우저 `localStorage` 기반 개인 옷장 저장
- 도시 검색·현재 위치 기반 실시간 날씨 조회
- 체감온도·강수확률·바람과 학교·회사·데이트·면접·야외·여행 장소를 함께 반영한 자동 코디
- 자동 추천 코디를 실사 피팅 슬롯으로 바로 전달
- 정면 전신사진과 키·몸무게·상/하체 중심 체형 프로필
- 브라우저 내 MediaPipe 포즈 감지로 어깨·골반·무릎·발목 기준점 자동 분석
- 사진 속 사람 크기와 위치에 맞춘 상품사진 크기·중심·길이 자동 보정
- 실제 상품사진 기반 상의·하의·아우터·원피스·신발 실사 AI 피팅
- 여러 상품을 순서대로 합성하는 한 벌 코디 생성
- 원본과 최근 Look A/B/C를 나란히 보는 빠른 비교 보드
- 전신사진과 결과 이미지를 `localStorage`에 저장하지 않는 개인정보 분리
- 등교·데이트·면접·산책 상황별 코디 조합
- 모바일/데스크톱 반응형 화면
- 사설 주소, 위험한 리디렉션, 과도한 응답 크기 차단

## 로컬 실행

```bash
npm install
npm run dev
```

실사 피팅은 공식 CatVTON 공개 Hugging Face Space의 ZeroGPU를 비인증 방식으로 사용합니다. API 키와 결제 크레딧은 필요하지 않습니다. 공개 무료 서버의 대기열이 길거나 일일 무료 사용량이 소진되면, 실제 상품사진의 배경을 제거해 전신사진에 배치하는 Wearly Instant Fit으로 자동 전환됩니다.

사진을 올리면 함께 포함된 MediaPipe Pose Landmarker가 브라우저 안에서만 전신 기준점을 찾습니다. 빠른 비교 모드는 고정 화면 비율을 쓰지 않고 어깨·골반·무릎·발목 좌표에 따라 상의·하의·아우터·원피스·신발의 크기와 위치를 각각 계산합니다. 포즈 감지가 어려운 사진은 사람 윤곽과 중앙 정렬 보정을 사용하는 폴백으로 계속 동작합니다. 모델과 WASM 파일은 `public/models`, `public/mediapipe`에 포함되어 있어 별도 키나 외부 모델 다운로드가 필요하지 않습니다.

CatVTON의 정밀 합성 범위는 상의·하의·아우터·원피스입니다. 신발은 실제 상품사진을 이용한 즉시 미리보기 방식으로 함께 적용됩니다. 즉시 미리보기는 상품의 원본 디테일은 유지하지만 몸에 따른 주름과 가림을 새로 생성하지는 않습니다.

- `빠른 비교 · 무제한`: Wearly Instant Fit으로 약 3초 안에 여러 조합을 비교하며 ZeroGPU 사용량을 소모하지 않습니다.
- `정밀 AI · 무료`: 최종 후보 코디에 CatVTON을 사용해 몸에 따른 주름과 가림을 생성합니다. 무료 한도나 대기열에 걸리면 즉시 미리보기로 자동 전환됩니다.

날씨는 API 키가 필요 없는 Open-Meteo Forecast/Geocoding API를 사용합니다. 서울·부산·제주 등 주요 국내 도시는 한글 이름으로 바로 찾고, 현재 위치도 지원합니다.

브라우저에서 `http://localhost:3000`을 엽니다.

## ⚠️ 참고사항

일부 쇼핑몰은 봇 접근이나 외부 이미지 로딩을 차단하기 때문에 상품의 상세 메타데이터 또는 이미지를 정상적으로 불러오지 못할 수 있습니다. 이 경우 URL에서 추정한 상품 정보와 색상 기반 대체 이미지가 표시되며, 실제 상품 이미지가 없는 경우 실사 피팅 대상에서 제외됩니다.

실사 피팅은 CatVTON 공개 ZeroGPU 데모를 사용하며, 결과 정확도는 전신사진·상품사진의 품질, 옷의 겹침 및 생성 모델의 특성에 따라 달라질 수 있습니다. 실제 사이즈 보장이나 구매 적합성 판정 기능은 제공하지 않습니다.

자동 코디 기능은 현재 옷장에 저장된 카테고리·스타일·계절·색상 정보를 점수화하는 MVP 추천 방식입니다. 날씨 데이터가 일시적으로 unavailable한 경우에도 기본 간절기 기준으로 추천을 제공합니다.
